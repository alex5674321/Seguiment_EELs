EEL JOURNAL UPDATE

The interface is now in English. Existing user-written content is preserved.

- My tasks: use the pencil to edit or × to delete a task in edit mode.
- Tasks: drag cards to reorder them, or use the up/down buttons.
- Activities: enter start and end dates and times; duration is calculated.
- Tracking: edit the title and summary of each weekly card.
- The notes section is called Housekeeping.
- Sidebar footer: We continue.

Keep your existing data/diary.json when updating application files.
Existing activities with start times and durations are compatible.
Changes made in edit mode are saved to GitHub, not automatically to local files.
See README.md for local development, publishing and browser checks.
